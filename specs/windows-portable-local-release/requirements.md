# Windows 免安装本地版发布需求

状态：设计与任务拆分完成，待确认后实施
优先级：P0（产品发布前）
关联文档：`docs/product-ui-and-user-interaction-design.md`、`docs/user-account-and-data-encryption-design.md`、`specs/real-email-ui-validation/`

## 1. 产品决策

Windows 首发形态调整为“签名的免安装本地版”：用户下载 ZIP、解压后直接运行 EXE，不要求管理员权限，也不执行安装程序。MSI/NSIS 只作为个人电脑或企业 IT 统一部署的可选交付物；浏览器本地精简版不进入当前 MVP。

免安装只解决“无需安装和管理员权限”，不承诺绕过企业 AppLocker、WDAC、Smart App Control、杀毒软件或网络策略。对于受管电脑，产品提供可核验的签名、哈希和 IT 审核资料，由企业按自身策略放行。

## 2. 目标与范围

### 2.1 目标

- 普通 Windows 用户无需安装即可完成发票导入、处理、复核和输出。
- 程序文件与用户数据分离，替换程序版本不会覆盖用户数据。
- 在启动前明确检查 WebView2、数据目录和数据库版本，错误可理解、可恢复。
- 发布包具有稳定发布者签名、完整性校验和企业审核所需材料。
- 继续遵守邮箱只读、授权码仅会话内存保存、MVP 本地数据不加密但明确告知的约束。

### 2.2 MVP 范围

- Windows 10/11 x64 免安装 ZIP；ARM64 是否首发在发布冻结时单独确认。
- 系统 WebView2 Evergreen Runtime 为默认运行时。
- 本机固定数据目录及用户可选的本机工作目录。
- 手动下载、退出、替换程序目录的更新方式。
- Authenticode 代码签名、SHA-256 清单、版本说明、第三方许可和 IT 审核包。
- 免安装环境下的 UI、真实只读邮箱和升级回归测试。

### 2.3 非目标

- 不绕过或削弱企业安全控制。
- 不在 MVP 内实现静默安装、驱动、Windows 服务、开机启动、文件关联或自动提权。
- 不在 MVP 内实现自动更新器、云同步、产品账号和应用层数据加密。
- 不把 SQLite 数据库直接放在 UNC、NAS、共享盘或同步盘上运行。
- 不把浏览器版作为免安装桌面版的等价替代；浏览器受限于 IMAP/SMTP、文件系统和后台任务能力。

## 3. 用户故事

1. 作为没有软件安装权限的员工，我希望解压后直接运行，以便不请求管理员授权。
2. 作为已有历史数据的用户，我希望更新程序时保留任务、发票和配置。
3. 作为非技术用户，我希望缺少运行环境时看到明确说明和安全的解决入口。
4. 作为受管电脑用户，我希望能把发布者、哈希、联网范围和文件路径交给 IT 审核。
5. 作为重视隐私的用户，我希望邮箱授权码不落盘，邮箱获取保持只读。
6. 作为测试人员，我希望用隔离的数据目录验证新版本，而不污染正式数据。

## 4. 功能需求与验收条件

### R1 免安装运行（P0）

WHEN 用户解压官方 ZIP 并启动主 EXE，THE SYSTEM SHALL 在普通用户权限下直接运行，且不写注册表安装项、不创建服务、不配置开机启动、不注册文件关联、不要求 UAC 提权。

验收：在无管理员权限的 Windows 10/11 标准用户上，解压到本地可写目录后可启动并完成核心流程；进程树中不存在安装器或提权子进程。

### R2 签名与完整性（P0）

WHEN 生成正式发布包，THE RELEASE PIPELINE SHALL 对所有自有可执行文件执行受信任时间戳的 Authenticode 签名，并在签名后生成 SHA-256 清单。

IF 任一自有 EXE 未签名、签名无效、发布者不一致或哈希清单不匹配，THEN THE RELEASE PIPELINE SHALL 阻止正式发布。

### R3 WebView2 运行时（P0）

WHEN 程序启动，THE NATIVE BOOTSTRAP SHALL 在创建主窗口前检查可用的 WebView2 Runtime。

IF 未检测到兼容运行时，THEN THE SYSTEM SHALL 不静默安装、不提权，显示“缺少 Microsoft Edge WebView2 Runtime”、官方获取方式、离线处理说明和退出操作。

系统 WebView2 Evergreen 是默认方案；包含 Fixed Version Runtime 的完整包仅作为后续可选交付，不得与精简包混淆。

### R4 程序与数据分离（P0）

WHEN 首次启动，THE SYSTEM SHALL 默认将持久数据写入 `%LOCALAPPDATA%\InvoiceAssistant\Data`，而不是 EXE 所在目录。

WHERE 用户选择自定义数据目录，THE SYSTEM SHALL 展示绝对路径并验证目录可写、空间充足且适合本地数据库。

IF 路径属于 UNC、网络映射盘、只读介质或已知同步目录，THEN THE SYSTEM SHALL 阻止或明确警告数据库使用风险，并要求选择本机目录。导出文件可由用户另行选择位置。

### R5 首次启动和透明告知（P0）

WHEN 用户首次启动，THE SYSTEM SHALL 依次展示运行环境检查、数据保存位置和 MVP 隐私说明。

隐私说明必须写明：数据在本机处理；MVP 本地数据库不进行应用层加密；邮箱授权码仅在当前会话内存中使用；关闭应用后需要重新输入。

### R6 邮箱安全约束（P0）

WHEN 用户输入邮箱授权码，THE SYSTEM SHALL 仅在当前进程内存保存，不写入数据库、配置、日志、崩溃报告、截图或测试产物。

WHEN 获取邮件，THE SYSTEM SHALL 使用只读邮箱访问语义，不移动、删除、标记已读、修改旗标或发送邮件；Concur 发送必须是用户单独确认的后续动作。

### R7 手动更新与数据迁移（P0）

WHEN 检测到新版本，THE SYSTEM SHALL 只提示版本、更新说明和官方下载入口，不在 MVP 内自动替换程序或请求提权。

WHEN 新版本首次打开旧数据库，THE SYSTEM SHALL 先校验兼容性并创建可恢复快照，再执行幂等迁移；迁移失败时保留原数据并给出回退步骤。

### R8 旧数据目录迁移（P0）

IF 检测到历史目录（例如 `%USERPROFILE%\.invoice-assistant`），THEN THE SYSTEM SHALL 展示来源、目标、数据量和迁移影响，由用户确认后复制、校验并切换；不得静默删除旧目录。

### R9 受管电脑边界（P0）

IF Windows 在进程启动前阻止 EXE，THEN THE PRODUCT DOCUMENTATION SHALL 说明这是系统或企业策略拦截，并提供 IT 审核包，不提供绕过策略、改名规避或关闭安全功能的做法。

IT 审核包至少包含发布者证书信息、版本、文件哈希、SBOM/第三方许可、程序和数据路径、所需网络域名与端口、权限清单，以及“不安装服务/驱动、不需要管理员权限”的声明。

### R10 可诊断性（P1）

WHEN 启动或任务失败，THE SYSTEM SHALL 生成脱敏诊断信息，包含应用版本、Windows 版本、WebView2 版本、数据目录、阶段和错误码，但不得包含授权码、邮件正文、完整发票内容或个人敏感字段。

### R11 发布包结构（P0）

THE RELEASE PACKAGE SHALL 包含主程序、必要运行库、README、隐私说明、版本说明、第三方许可、`version.json` 和 `SHA256SUMS`；不得要求用户执行 PowerShell、批处理或注册表脚本才能启动。

### R12 Windows 兼容性验证（P0）

BEFORE 正式发布，THE TEST SUITE SHALL 覆盖 Windows 10/11 标准用户、中文及空格路径、Downloads/Documents/本地 USB 目录、100%/125%/150% 缩放、系统 WebView2 多版本、Defender/SmartScreen、缺失运行时、替换升级、数据库回退和两轮真实邮箱只读回归。

## 5. 发布门禁

以下条件全部满足才允许发布免安装本地版：

- 核心功能、UI 自动化、Rust/前端测试和真实邮箱只读回归全部通过。
- 免安装包在标准用户环境中无需 UAC 即可运行。
- 程序目录可整体替换，正式数据和用户输出保持不变。
- WebView2 缺失、数据目录不可用和迁移失败均有可执行的恢复路径。
- 所有自有 EXE 签名有效，签名后哈希与清单一致。
- 发布包及测试产物通过密钥、邮箱正文和隐私数据扫描。
- IT 审核包、用户更新说明、备份与回退说明齐备。

## 6. 待发布冻结时确认

- 首发仅 x64，还是同时提供 ARM64。
- 代码签名证书类型、证书主体和时间戳服务。
- 是否提供较大的 WebView2 Fixed Runtime 完整包；若提供，必须单独命名并验证 Microsoft 的目录与访问控制限制。
- 官方下载和版本清单的托管位置。
