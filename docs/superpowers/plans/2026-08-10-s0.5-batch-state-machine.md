## 目标

实现批次生命周期状态机，包含状态转换验证、时间戳跟踪和完整的测试覆盖。

## 背景

当前 `invoice-store` 中的 `Batch` 结构体和 `update_batch_status()` 方法缺少：
1. 状态转换验证逻辑（可以从 Draft 直接跳到 Completed）
2. 完整的时间戳字段（只有 `submitted_at`，缺少 `approved_at`、`completed_at`、`rejected_at`）
3. 全面的状态转换测试

## 当前状态

### BatchStatus 枚举（已存在）
```rust
pub enum BatchStatus {
    Draft,      // 草稿
    Submitted,  // 已提交
    Approved,   // 已批准
    Completed,  // 已完成
    Rejected,   // 已驳回
}
```

### Batch 结构体（部分字段）
```rust
pub struct Batch {
    pub id: i64,
    pub status: BatchStatus,
    pub submitted_at: Option<NaiveDateTime>,
    // 缺少: approved_at, completed_at, rejected_at
}
```

### 现有方法
- `ledger_db.rs::update_batch_status()` - 无验证逻辑，只设置 `submitted_at`

## 状态转换矩阵

| 当前状态 | 允许转换到 | 设置时间戳 |
|---------|-----------|-----------|
| Draft | Submitted, Rejected | `submitted_at`, `rejected_at` |
| Submitted | Approved, Rejected | `approved_at`, `rejected_at` |
| Approved | Completed, Rejected | `completed_at`, `rejected_at` |
| Completed | (终态) | - |
| Rejected | (终态) | - |

### 非法转换示例
- Draft → Completed
- Draft → Approved
- Submitted → Completed
- Completed → 任何状态
- Rejected → 任何状态

    fn is_valid_transition(from: &BatchStatus, to: &BatchStatus) -> bool {
        match (from, to) {
            (BatchStatus::Draft, BatchStatus::Submitted) => true,
            (BatchStatus::Draft, BatchStatus::Rejected) => true,
            (BatchStatus::Submitted, BatchStatus::Approved) => true,
            (BatchStatus::Submitted, BatchStatus::Rejected) => true,
            (BatchStatus::Approved, BatchStatus::Completed) => true,
            (BatchStatus::Approved, BatchStatus::Rejected) => true,
            _ => false,
        }
    }
