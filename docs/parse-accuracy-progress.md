### 技术要点

#### 空间文本框配对
- **同行判定**：y 中心差 ≤ 15px（`SAME_LINE_TOLERANCE`）
- **右邻判定**：x ≥ label.right - 5px（容忍轻微重叠）
- **列对齐判定**：x 差 ≤ 20px（`x_tolerance`）

#### 三级降级策略（税额）
1. **同框/同行**：`find_value()` 查找标签右侧值
2. **列求和**：`find_in_column_sum()` 汇总明细行（排除合计行）
3. **列单值**：`find_in_column()`取第一个满足条件的值

#### 合计行过滤
```rust
// 文本包含"合计"或"合 计"
if text.contains("合计") || text.contains("合 计") {
    continue;
}
// 同行有"合"或"计"单字（碎片化版式）
let has_total_marker = same_line_boxes
    .iter()
    .any(|b| b.text.contains("合") || b.text.contains("计"));
if has_total_marker {
    continue;
}
```
