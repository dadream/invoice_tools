# 秘密与隐私数据处理规则

## 1. 数据分类

| 类别 | 示例 | 规则 |
|---|---|---|
| 秘密 | 邮箱授权码、OAuth Token、SMTP 凭据、签名私钥 | 只进受控内存或专用签名环境；禁止入库、日志、截图、报告、命令行和 Git |
| 高敏隐私 | 邮件正文、原始附件、税号、完整票号、金额明细 | 只在用户本机数据目录处理；测试证据使用合成样本或脱敏摘要 |
| 个人标识 | 完整邮箱、姓名、公司名、本机用户名和绝对路径 | UI 按功能显示；日志和报告掩码或移除 |
| 可公开元数据 | 版本、错误码、计数、脱敏哈希、阶段 | 可进入诊断和发布证据 |

## 2. 允许的数据流

- `.env.local` 仅作为本机真实验证的秘密来源，必须被 Git 忽略。
- UI 授权码输入通过一次 IPC 进入 Rust，会话建立后立即清空输入。
- Rust 使用 `Zeroizing<String>` 保存当前会话凭据；退出、清除或替换时销毁。
- 真实验证报告只保存掩码邮箱、日期边界、数量、不可逆哈希和结论。
- 未加密备份允许包含用户选择备份的发票与台账，但必须明确警告并排除秘密、临时缓存和普通日志。

## 3. 禁止

- 不得读取、打印、复制或提交 `.env.local` 的值。
- 不得将秘密放在 PowerShell/CMD 参数、进程标题、测试名称、异常消息、WebDriver 参数或 CI 变量输出中。
- 不得记录邮件正文、主题全文、完整票号、税号、金额明细或附件路径。
- 不得把真实样本复制到仓库、`target`、`ui/dist`、截图目录或发布 ZIP。
- 不得通过外部 LLM、遥测、崩溃上传或后台服务发送产品数据。

## 4. 发布前检查

1. 确认 `.env.local`、`*.eml`、真实样本和 `reports/` 被忽略。
2. 扫描被 Git 跟踪文件、构建日志、数据库、发布目录和测试报告中的秘密模式。
3. 使用合成授权码验证扫描器可命中；演练文件必须在扫描后删除。
4. 检查数据库 `credentials` 表为空，应用重启后 UI 要求重新输入授权码。
5. 检查日志只包含白名单字段。
6. 发现疑似泄露时立即停止测试、隔离产物、撤销授权码并登记 P0。

## 5. 截图与 UI 测试

- 输入真实授权码时禁止录屏和截图。
- 含真实发票原件的页面禁止截图；使用合成夹具复现 UI 状态。
- 自动 UI 测试只使用假授权码；真实自动化只能引用后端建立的无秘密会话标识。
