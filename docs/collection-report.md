## 观察到的问题

1. **铁路票缺失**：目标日期范围内无铁路发票（pdf-rail），需要扩大日期范围或从其他月份补充至少3张12306铁路电子客票。

2. **机票行程单不足**：只采集到2张（曹操出行误分类为flight，实为网约车），实际机票行程单为0张，需补充3张。

3. **图片格式不足**：只采集到6张图片（部分为邮件内的logo/广告图片，非发票扫描件），需手工补充4张真实的纸质发票扫描或拍照图片。

4. **误分类问题**：曹操出行的行程报销单被分类为 pdf-flight，但实际应为网约车服务（属于 pdf-vat），这是分类器的已知限制。

5. **附件判定准确**：101个附件中正确识别并过滤掉32个非发票文件（如logo、广告图片），重复检测有效（丢弃5个重复）。

6. **平台识别**：成功识别多个主流平台（美团、滴滴），但大量发票来自 unknown 平台（直接从税务系统或企业开票系统发送）。
