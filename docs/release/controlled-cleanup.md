# 免安装版本受控清除设计

## 用户流程

1. 在“设置 → 数据”点击“查看清除预览”。
2. 应用展示程序目录、数据目录、类别、文件数量和大小；此时不删除任何内容。
3. 用户选择清除本机数据和/或标准 portable 产品文件。
4. 用户输入确认短语“永久清除”，并通过最后一次系统确认。
5. 主程序把自身复制到系统临时目录，写出无通配符清除计划，启动临时副本后退出。
6. 临时副本等待数据库和主 EXE 句柄释放，只删除计划中通过二次校验的产品文件；完成后显示原生结果。

## 安全边界

- 拒绝相对路径、`..`、磁盘根目录、用户主目录、UNC/网络共享、符号链接、联接点和其他重解析点。
- 数据目录必须与本机 `InvoiceAssistant/Data`（或测试覆盖目录）精确匹配。
- 程序清除只对文件名为 `InvoiceAssistant.exe` 且带产品 `manifest.json` 的标准 portable 包开放。
- 程序目录只删除 manifest 声明的产品文件、manifest 本身和校验清单；同目录的用户文件始终保留。
- 所有文件和目录在主进程中枚举为绝对路径；辅助进程删除前再次检查边界和文件类型，不使用通配符。
- 不写注册表、不登记重启删除项。正在运行的临时清理副本无法在 Windows 中自删，会留在系统 `%TEMP%`，文件名为 `InvoiceAssistant-cleanup-<随机值>.exe`，可由系统临时文件维护或用户手动删除。
- 清理失败时保留未能删除的文件并显示数量，不扩大目标范围。

## 已验证与待验证

自动测试覆盖安全根目录、显式深度优先计划、manifest 路径穿越、未声明文件拒绝。标准 portable 包上的实际清除属于破坏性发布验证，必须在隔离的临时 DataRoot 和一次性解压目录中执行并记录清单差异。
