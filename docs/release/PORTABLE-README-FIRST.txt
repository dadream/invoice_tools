发票报销助手 0.1.0 — Windows x64 免安装内部 Alpha

重要：本候选包未签名，仅限已授权的内部测试，不得公开分发。

使用方法：
1. 将整个 ZIP 解压到本机普通文件夹；不要从 ZIP 内直接运行。
2. 双击 InvoiceAssistant.exe。应用不安装、不申请管理员权限。
3. 首次启动需要系统已有 Microsoft Edge WebView2 Evergreen Runtime。
4. 默认数据位于 %LOCALAPPDATA%\InvoiceAssistant\Data，不写入程序目录。
5. 邮箱授权码只在当前运行会话内存中使用，退出后需重新输入。

企业电脑若阻止启动：
- 不要绕过安全策略；将 IT-REVIEW.md、SHA256SUMS.txt 和 SBOM.cdx.json 提交给企业 IT。
- WebView2 缺失时，由企业 IT 按微软官方渠道部署；本软件不会静默安装。
- 两个自有 EXE 的静态 DLL 依赖在链接期限定为 System32；运行期排除当前目录、PATH 和未验证应用目录，只登记已校验哈希的 OCR 目录。出现 DLL 安全初始化错误时请重新下载完整包，不要从其他网站补 DLL。

数据和隐私：
- 发票、邮箱地址和报销数据属于用户并保存在本机。
- “数据与备份”可导出未加密 ZIP 并在另一台电脑导入；备份不包含授权码、日志或本机邮箱配置。
- 流水线按阶段写入校验检查点；解析结果保存格式版本和解析器版本，不兼容检查点会被拒绝；运行中可“安全停止”，等待当前文件结束后保留最近检查点并在首页恢复。
- 不要把真实授权码、原始发票或日志发送到公开缺陷平台。

更新、迁移与回退：
- 检测到旧版 ledger.db 时，应用先在 Data\migration-backups 创建经版本与 SQLite 完整性校验的独立快照，再用单一事务迁移；失败不会提交任何表、索引、字段或版本变化。
- 若迁移失败，启动错误会显示快照路径。保持应用关闭，先复制保留当前 Data 目录，再将当前 ledger.db 改名留存，把对应快照复制为 Data\ledger.db，使用原版本程序打开；不要移动或覆盖唯一快照。
- 若新版本已继续录入或修改数据，不要直接回退旧快照，否则会丢失迁移后的新记录；先停止使用并联系支持。迁移快照不包含邮箱授权码。

审核与输出：
- 草稿批次可编辑发票字段、确认非重复、创建/移动/合并归组，并按相反顺序撤销审核操作。
- 归组歧义、重复项或签章失败未处理时不能提交。
- 推荐输出包包含 Excel、CSV、PDF 台账、A4 规范化打印合订本和带 SHA-256 索引的原件 ZIP；完成目录不会被覆盖。
- PNG/JPG/JPEG/WebP/BMP 和扫描 PDF 使用包内离线 OCR；无需联网、Python 或额外安装。OCR/低置信结果一律标为待人工复核。
- OCR 由同目录 `invoice-ocr-worker.exe` 隔离执行，最大并发 1、每文件 45 秒超时；不要删除、移动或单独替换该文件及 `ocr` 目录。

Concur 收据邮件：
- 仅已审批/完成批次可建立本地计划；先一张试发、人工确认 Concur 行为后才允许剩余发送。
- 本内部 Alpha 在后端和打包门禁中强制关闭真实 SMTP；建立计划不会联网，发送按钮不可用。
- 不会创建、填写、关联或提交 Concur 报销单。XML/OFD 需先生成 PDF/图片收据。

已知限制：
- 历史测试夹具不能证明为合成数据；当前工作树已隔离，但 Git 历史/远端缓存/旧制品清理尚未完成。本包仅限授权内部验证，P0 关闭前不得公开发布。
- 图片与扫描 PDF OCR 已通过合成样本，但真实票据准确率/性能、OFD 栅格 OCR、完整键盘操作和 100%/125%/150% 缩放实测尚未达到公开发布门禁。
- 检查点恢复已通过自动测试，但仍需真实进程强杀/重启人工走查；A4 合订本仍需打印预览确认。
- “数据与备份”已提供清除预览和受控清理；清理器会在系统临时目录留下一个随机命名的临时 EXE，不写注册表，可由系统或用户后续删除。
- “版本与支持”仅在用户点击时读取固定 HTTPS 清单；当前内部 Alpha 未配置正式地址，因此不会联网。不得用于真实 Concur 发送。
- 遇到数据异常立即停止使用并保留 Data 目录副本。
