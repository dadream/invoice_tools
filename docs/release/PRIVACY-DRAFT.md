# 隐私说明（内部 Alpha 草案）

本草案仅用于内部验证，不能替代公开版本的正式隐私政策。

## 数据处理

- 发票文件、解析字段、邮箱地址、批次、设置和日志默认仅保存在用户电脑。
- 邮箱授权码仅用于当前进程内的 IMAP 会话，不写入数据库、日志、备份或测试报告。
- 软件不会自动上传发票、日志或使用数据，不包含匿名遥测。
- 只有用户主动执行邮箱获取时才连接所配置邮箱服务；MVP 不自动联网检查更新。

## 邮箱只读

邮箱使用 TLS IMAP，采用只读 `EXAMINE` 和 `BODY.PEEK[]`，并比较读取前后邮件 FLAGS。发现变化时停止流程。软件不执行 STORE、EXPUNGE、APPEND、DELETE 或 MOVE。

## 本地文件与日志

- 默认数据目录：`%LOCALAPPDATA%\InvoiceAssistant\Data`
- 日志目录：`Data\logs`
- 日志不得包含授权码、邮件正文、完整票号或原始发票内容。

## 备份

规划中的 MVP 备份为用户主动生成的未加密 ZIP。备份不得包含授权码或会话秘密；用户应自行控制备份文件的存储和传输。
