# 0.1.2 内部 Alpha 发布说明

## 变更

- Concur 能力验证：显示已连接账号，并逐项验证报销单读取、草稿创建、费用创建和发票上传权限。
- Concur 草稿交付：支持通过企业 API 创建未提交报销单与费用草稿、上传合订 PDF 并回读结果。
- 安全控制：OAuth 凭据和令牌仅保存在当前程序会话；软件不自动提交报销单。
- 仓库说明：精简 README，明确产品范围、开发验证、免安装构建和安全边界。

## 发布说明

本版本为 Windows x64 免安装、未签名的内部 Alpha。Concur 功能需使用企业批准的 OAuth 应用，并在目标租户完成验证。
