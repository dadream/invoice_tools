# 用户协议（内部 Alpha 草案）

本草案只用于内部测试，不构成公开发行许可。

1. 本软件仅供获准的内部 Alpha 用户评估发票收集、解析、审核和本地输出流程。
2. 测试用户应保留原始数据副本，并在发现金额、票号、归组或输出异常时停止使用。
3. Concur 浏览器测试只允许用户明确授权后使用内置虚构样例创建未提交草稿；不得提交测试报销，测试后由用户自行检查并删除草稿。真实批次交付须使用同一账号及映射完成测试，并由用户另外授权；不得向不相关第三方发送数据。
4. 不得绕过企业安全策略、代码签名警告、WebView2 部署策略或管理员控制。
5. 测试反馈必须脱敏，不包含授权码、完整票号、税号、邮件正文或原始发票截图。
6. 公开 Beta 前将由发布主体补充正式版权、许可、支持渠道和法律文本。
