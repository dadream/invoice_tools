## 3. 软件描述

### 3.1 核心功能

本软件提供以下功能：

| 功能模块 | 描述 |
|---------|------|
| **邮箱采集** | 从 IMAP 邮箱自动下载发票附件 |
| **发票解析** | 支持 XML、OFD、PDF 格式发票字段提取 |
| **智能归组** | 基于时间和地点自动归类差旅行程 |
| **去重验证** | 防止重复报销同一张发票 |
| **批次管理** | 创建和管理报销批次 |
| **导出功能** | 生成 Excel 明细表和 PDF 台账 |

### 3.2 技术架构

- **本地优先**: 所有数据存储在您的设备上
- **离线可用**: 核心功能无需网络连接（除邮箱采集）
- **开源透明**: 源代码公开可审查
