# 隐私政策

**生效日期**: 2026-08-17  
**最后更新**: 2026-08-17

---

## 1. 概述

发票助手（Invoice Assistant）是一款**本地优先**的桌面应用程序，帮助用户从邮箱采集、解析和管理差旅发票。我们深知用户财务数据的敏感性，因此设计时遵循以下原则：

- **本地处理优先**: 所有核心功能在本地设备运行
- **最小数据收集**: 仅收集必要的匿名使用统计
- **用户完全控制**: 用户随时可以导出、删除或禁用数据收集

---

## 2. 我们收集哪些信息

### 2.1 用户主动提供的信息

| 数据类型 | 用途 | 存储位置 |
|---------|------|---------|
| **邮箱地址** | 用于 IMAP 连接采集发票附件 | 本地数据库（`~/.invoice-assistant/accounts.db`） |
| **邮箱密码** | IMAP 认证 | **AES-256-GCM 加密**后存储，主密钥存于系统 Keychain |
| **常驻城市** | 用于差旅归组判断 | 本地数据库（`~/.invoice-assistant/ledger.db`） |
| **发票文件** | 解析、去重、归组 | 本地文件系统（`~/.invoice-assistant/invoices/`） |
| **批次数据** | 报销台账管理 | 本地数据库（`ledger.db`） |

**关键承诺**:
- ✅ 所有数据存储在**用户本地设备**
- ✅ **永不上传**到任何云端服务器
- ✅ 密码使用行业标准加密（AES-256-GCM + 系统 Keychain）

### 2.2 自动收集的匿名使用数据（可选）

如果用户启用匿名遥测（默认**关闭**），我们将收集以下**聚合统计信息**：

| 数据类型 | 示例 | 用途 |
|---------|------|------|
| **应用版本** | `v0.5.0` | 版本兼容性分析 |
| **操作系统** | `Windows 11`, `macOS 14`, `Ubuntu 22.04` | 跨平台优化 |
| **功能使用频率** | `parse_count: 42`, `export_count: 3` | 功能优先级决策 |
| **错误类型统计** | `ParseError: 2`, `ImapTimeout: 1` | 稳定性改进 |
| **性能指标** | `avg_parse_time: 1.2s` | 性能优化 |

**不收集**:
- ❌ 发票内容（金额、发票号、公司名等）
- ❌ 邮箱地址或密码
- ❌ 任何可识别个人身份的信息（PII）
- ❌ IP 地址或设备唯一标识符

**控制权**:
- 用户可在设置中**一键禁用**遥测
- 禁用后**立即停止**数据收集，已收集数据不影响应用功能

## 4. 数据存储与安全

### 4.1 本地存储

所有用户数据存储在用户本地设备：

```
~/.invoice-assistant/
├── accounts.db          # 邮箱账号（密码已加密）
├── ledger.db            # 批次和发票记录
├── invoices/            # 原始发票文件
│   └── 2026-07/
│       ├── 001.xml
│       └── 002.pdf
└── .master-key          # 加密主密钥（Linux/WSL）
```

**Windows/macOS**: 主密钥存储在系统 Keychain（Windows Credential Manager / macOS Keychain）  
**Linux/WSL**: 主密钥存储在文件 `~/.invoice-assistant/.master-key`，权限设为 `0600`（仅当前用户可读）

### 4.2 加密机制

| 组件 | 加密算法 | 密钥管理 |
|------|---------|---------|
| 邮箱密码 | AES-256-GCM | 主密钥由系统 Keychain 或文件（0600）保护 |
| 12-byte nonce | 随机生成 | 每次加密使用不同 nonce |
| 16-byte 认证标签 | AEAD | 防止篡改 |

### 4.3 网络通信

| 连接类型 | 协议 | 数据内容 | 频率 |
|---------|------|---------|------|
| **IMAP 邮箱服务器** | IMAP over TLS | 邮箱认证凭证、邮件元数据、附件下载 | 用户触发采集时 |
| **遥测服务器**（可选） | HTTPS | 匿名聚合统计（无 PII） | 每周一次（若启用） |

**关键保障**:
- ✅ 所有网络连接使用 **TLS 加密**
- ✅ 发票内容**永不上传**到任何服务器
- ✅ 遥测数据**完全匿名**，无法追溯到个人

## 5. 数据共享与披露

### 5.1 我们不会出售您的数据

我们**永不**出售、出租或交易用户数据给第三方。

### 5.2 我们不会与第三方共享

除以下情况外，我们**不会**共享用户数据：

| 情况 | 示例 | 共享内容 |
|------|------|---------|
| **法律要求** | 法院传票、监管调查 | 仅依法必须提供的最小范围数据 |
| **用户明确授权** | 用户主动导出数据到 Concur 等系统 | 用户选择的数据 |

**但请注意**: 由于应用设计为**本地优先**，我们的服务器**不存储**用户的发票数据，因此即使收到法律请求，我们也**无法提供**不存在的数据。

## 6. 用户权利

### 6.1 查看数据

所有数据存储在用户本地设备：
```bash
# 查看数据库位置
ls ~/.invoice-assistant/

# 查看发票文件
ls ~/.invoice-assistant/invoices/
```

### 6.2 导出数据

- **批次导出**: 在应用中选择批次 → 导出为 Excel
- **完整导出**: 复制整个 `~/.invoice-assistant/` 目录

### 6.3 删除数据

- **删除单个批次**: 在应用中选择批次 → 删除
- **删除所有数据**:
  ```bash
  # 完全卸载应用和数据
  rm -rf ~/.invoice-assistant/
  ```

### 6.4 禁用遥测

设置 → 隐私 → 关闭"匿名使用统计"开关

## 7. 儿童隐私

本应用**不针对 13 岁以下儿童**设计，不会故意收集儿童信息。如果发现误收集，请联系我们删除。
