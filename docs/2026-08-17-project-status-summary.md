## ⚠️ 当前阻塞项

### 系统依赖问题（WSL/Linux）

编译失败，缺少：
- `libcairo`
- `libglib-2.0`
- `libwebkit2gtk-4.1`

**解决方案**（需要用户执行）：

```bash
sudo apt-get update
sudo apt-get install -y \
    libwebkit2gtk-4.1-dev \
    build-essential \
    curl \
    wget \
    libssl-dev \
    libgtk-3-dev \
    libayatana-appindicator3-dev \
    librsvg2-dev
```

安装后即可：
```bash
source scripts/tauri-env.sh
cargo build -p invoice-assistant
cd src-tauri && cargo tauri dev
```
