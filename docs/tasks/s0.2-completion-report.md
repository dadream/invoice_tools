## 三、IPC 错误契约

### 3.1 契约定义

**JSON 形状** (固定，前后端联动修改):
```json
{
  "kind": "validation",
  "message": "姓名不能为空",
  "recoverable": true
}
```

**字段说明**:
- `kind`: `"database" | "parse" | "network" | "io" | "validation" | "internal"` (snake_case)
- `message`: 面向用户的中文错误描述
- `recoverable`: 布尔值，`true` 表示用户可重试，`false` 表示需查日志或报告问题

| 层 | 文件 | 类型/接口 |

| 前端 | `ui/src/lib/ipc.ts` | `type ErrorKind` + `interface AppError` + `isAppError()` + `toAppError()` |

**可恢复性分类**:
- 可恢复: `Network`, `Validation`, `Io`
- 不可恢复: `Database`, `Parse`, `Internal`

## 五、Linux sysroot 方案说明

### 5.1 为什么需要

- 本机是 WSL2 Ubuntu 22.04，无 root 权限 (`sudo` 需要密码)
- Tauri 依赖 `webkit2gtk-4.1-dev`、`libgtk-3-dev` 等包，系统未安装
- 配置的 apt 镜像 (清华源) 对 `.deb` 文件返回 403 Forbidden

### 5.2 方案实现

**安装** (`scripts/setup-linux-deps.sh`):
1. 用 `apt-get install --print-uris` 解析依赖闭环 (189 个包)
2. 把 URL 的 `https://mirrors.tuna.tsinghua.edu.cn` 改写为 `https://archive.ubuntu.com`
3. `curl` 并行下载 `.deb` 包到临时目录
4. `dpkg-deb -x` 解包到 `~/.local/tauri-sysroot` (292 MB)
5. 修复悬空符号链接 (dev 包的 `.so` 指向系统运行时库)

**使用** (`scripts/tauri-env.sh`):
```bash
export PKG_CONFIG_SYSROOT_DIR="$HOME/.local/tauri-sysroot"
export PKG_CONFIG_PATH="$SYSROOT/usr/lib/x86_64-linux-gnu/pkgconfig:..."
export LD_LIBRARY_PATH="$SYSROOT/usr/lib/x86_64-linux-gnu:..."
export RUSTFLAGS="-L $SYSROOT/usr/lib/x86_64-linux-gnu -C link-arg=-Wl,-rpath,..."
```

**验证**:
```bash
$ source scripts/tauri-env.sh
$ pkg-config --exists webkit2gtk-4.1 && echo OK
OK
$ gcc test.c $(pkg-config --cflags --libs webkit2gtk-4.1) -o test && ./test
(链接成功，可执行)
```

### 5.3 局限与后续

- **非标准环境**: `RUSTFLAGS` 全局设置会让 `cargo` 重新编译所有依赖，拖慢增量构建
- **仅限本机**: CI 或其他开发机应直接 `sudo apt-get install libwebkit2gtk-4.1-dev` (已写入 `docs/tauri-build-setup.md`)
- **与 SQLite 冲突**: `RUSTFLAGS` 中的 `-rpath` 让 `invoice-store` crate 的 `libsqlite3-sys` 链接失败 (`undefined symbol`)。这是已知问题，超出 S0.2 范围，后续通过隔离 `RUSTFLAGS` 作用域或 CI 上改用系统包管理器解决。
