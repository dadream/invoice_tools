## 关键问题解决

### SQLite 链接错误
**问题:** rusqlite 0.32 需要 `sqlite3_error_offset` (SQLite 3.38.0+)，但 Tauri sysroot 使用 SQLite 3.37.2

**解决方案:** 降级 rusqlite 从 0.32 → 0.27
- rusqlite 0.27 不使用 `sqlite3_error_offset`
- 所有测试通过
- 无 API 破坏性变化

**文件修改:** `crates/invoice-store/Cargo.toml`
```toml
rusqlite = { version = "0.27", features = ["bundled"] }
```
