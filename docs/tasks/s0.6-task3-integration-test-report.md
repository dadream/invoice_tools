## Critical Issue Resolved

### SQLite Linking Error
**Problem:** `rusqlite 0.32` requires `sqlite3_error_offset` (introduced in SQLite 3.38.0), but Tauri sysroot uses SQLite 3.37.2.

**Root Cause:** 
- Tauri sysroot at `~/.local/tauri-sysroot/usr/lib/x86_64-linux-gnu/libsqlite3.so.0.8.6` links to system SQLite 3.37.2
- The `RUSTFLAGS="-L $LIBDIR"` in `tauri-env.sh` causes linker to find old SQLite despite `bundled` feature
- The `-Wl,-rpath` forces runtime to use old library

**Solution:** Downgraded `rusqlite` from `0.32` → `0.27` in `crates/invoice-store/Cargo.toml`
- rusqlite 0.27 does not use `sqlite3_error_offset`
- All tests pass with 0.27
- No API breakage for our usage
