## 当前问题

### ⚠️ 系统依赖缺失（WSL/Linux 特定）

编译失败原因：
```
Package cairo was not found
Package glib-2.0 was not found
```

**解决方案**（需要用户手动执行）:

```bash
# Ubuntu/Debian
sudo apt-get update
sudo apt-get install -y \
    libwebkit2gtk-4.1-dev \
    build-essential \
    curl \
    wget \
    libssl-dev \
    libgtk-3-dev \
    libayatana-appindicator3-dev \
    librsvg2-dev

# 或者 Fedora/RHEL
sudo dnf install webkit2gtk4.1-devel \
    openssl-devel \
    curl \
    wget \
    libappindicator-gtk3 \
    librsvg2-devel

# 或者 Arch
sudo pacman -S webkit2gtk base-devel curl wget openssl appmenu-gtk-module gtk3 libappindicator-gtk3 librsvg
```

### IPC 错误处理

所有后端命令返回 `Result<T, AppError>`，自动序列化为：

```json
{
  "type": "Database" | "Parse" | "Network" | "Io" | "Validation" | "Internal",
  "message": "错误详情"
}
```

前端通过 `invokeSafe<T>()` 调用，返回 discriminated union：

```typescript
type InvokeResult<T> = 
  | { ok: true; data: T }
  | { ok: false; error: AppError }
```
